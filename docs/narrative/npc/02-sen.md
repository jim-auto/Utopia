# セン（Sen）

| 項目 | 内容 |
|------|------|
| **拠点** | パリンプセスト（月） |
| **役割** | 記憶管理者。個人記憶と公共記録の境界を守る |
| **六軸** | 継続・自律 |

## 守っている価値

**残留の尊厳** — 安全な家があるからこそ、出発は特別扱いしてはいけない。

また **忘れる権利** と **記録の義務** の両立。どちらか一方に倒れない制度を求める。

## 恐れているもの

- 記録されない異議（次世代への盗み）
- 「勇気」という言葉で、残る者の人生が劣ると暗示されること
- モザイクが、反対意見を **脚注** に追いやること

## アスターとの関係

尊重しているが、同意はしない。手紙のやり取りは続いている（プレイヤーが両方に居合わせられない）。

## 拒否フック

| 拒否 | 問い例 |
|------|--------|
| 記憶の編集 | 「忘却を拒んだあなたが、他者の記憶を消す制度を設計するのか？」 |
| 家族 | 「記録に残らない絆は、家族と呼べる？」 |
| 名声 | 「誰も知らない善は、なお善か？」 |

## 信頼段階

| 段階 | 変化 |
|------|------|
| 低 | 記録庫の見学のみ |
| 中 | 削除申請の実例を見せる |
| 高 | 自分が消したくない記憶の存在を打ち明ける |

## 代表台詞

> 安全な家があるのに出ていくことを、我々は勇気と呼ぶべきではない。残る者の人生を二流にしてはならない。

> 記録されない異議は、次世代への盗みだ。

## 執筆禁止

- 記録管理者を情報統制の悪役にしない
- 忘却を「弱さ」として描かない
