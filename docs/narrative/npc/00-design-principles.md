# NPC設計の原則

[← ナラティブ目次](../00-index.md)

## 絶対ルール（GDD §12 から）

- **悪人にしない** — 裏の支配者・秘密結社・カルト化禁止
- **説教しない** — 哲学は制度・時間・身体で見せる。台詞は短く、具体的に
- **正解を持たせない** — NPCも「自分の答え」は持つが、プレイヤーを屈服させない
- **退出できる** — すべての主要NPCは、プレイヤーとの関係を終えられる

## 善と善の衝突

各NPCは「悪意」ではなく **本物の価値** を守る。

| 避ける | 代わりに |
|--------|---------|
| 「お前は間違っている」 | 「私はこれを失いたくない」 |
| 長い講義 | 一つの具体例・一つの損失 |
| 単一の正論 | 文脈付き理由（理由の地図） |

## 証言段階との関係

プレイヤー（可能未来の証人）への態度は **信頼段階** で変わる。攻撃力ではなく「言葉の重み」。

| 段階 | NPCの態度 |
|------|----------|
| 客人 | 礼儀正しいが核心を話さない |
| 参加者 | 自分の試行に意見を求める |
| 預かり者 | 秘密・反対意見を預ける |
| 証言者 | 文明規模の決定を共に記録する |

## 開始選択「拒否したもの」

主人公が拒否した価値は、NPCの **鏡** になる。説教ではなく **問い** として使う。

| 拒否 | 問いの方向 |
|------|-----------|
| 永遠の生命 | 「終わりを選ぶ勇気は、逃避とどう違う？」 |
| 家族 | 「血縁のない約束は、家族より弱い？」 |
| 名声 | 「記録されない選択は、存在しなかったこと？」 |
| 記憶の編集 | 「忘れないことを選ぶ者が、他者の忘却を設計していい？」 |
| 集団意識 | 「境界を守る者が、モザイクを信じられる？」 |
| 芸術的成功 | 「完成しない作品を、なお作品と呼べる？」 |

## 台詞のトーン

- **文長**: 1発言 1〜3文。引用可能な1文を必ず含める
- **語彙**: 日常語＋その人の専門比喩（記録、軌道、音、条文）
- **感情**: 怒りより **疲れ・愛着・恐れ** を優先
