# ソリ（Soli）

[← NPC原則](00-design-principles.md) | [関係図](07-relationships.md)

| 項目 | 内容 |
|------|------|
| **拠点** | アトリエ（火星） |
| **役割** | 作曲家。一回性を共同体の約束で成立させる |
| **六軸** | 熟達・関係 |

## 守っている価値

**一回性** — 瞬時に生成できる時代に、価値は希少データではなく **共同の制約** にある。

「一度だけ」は損失ではなく、**贈り物の形** だと考える。

## 恐れているもの

- 約束が共同体の所有物に変わること（個人の記憶まで縛る）
- 一回性がエリートの特权になること
- 作品が「伝統」に変換され、約束が形骸化すること

## 二十年後の争い

演奏者が子どもに断片を教える — ソリは **個人の記憶** まで共同体の規則に含めない。

| 立場 | 価値 |
|------|------|
| 共同体 | 一回性 |
| ソリ | 自律・記憶 |
| 子ども | 文化継承 |

## 拒否フック

| 拒否 | 問い例 |
|------|--------|
| 芸術的成功 | 「完成しない交響曲を、なお作品と呼べる？」 |
| 名声 | 「誰も知らない演奏に、あなたは居合わせるか？」 |
| 記憶の編集 | 「忘れないことを選んだ者に、沈黙の重さはわかる？」 |

## 信頼段階

| 段階 | 変化 |
|------|------|
| 低 | 楽譜ではなく「約束の範囲」の話のみ |
| 中 | 会場建設・練習にプレイヤーを招く |
| 高 | 破約した場合も責めず、「次に何を選ぶか」を問う |

## 代表台詞

> 記録しない。再演しない。——価値あるのは、数千人が一度だけと約束することだ。

> 自分の記憶まで、共同体の所有物ではない。
