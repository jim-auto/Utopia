# ナギ（Nagi）

[← NPC原則](00-design-principles.md) | [関係図](07-relationships.md)

| 項目 | 内容 |
|------|------|
| **拠点** | アビス（エウロパ深層） |
| **役割** | 深層探査共同体の調整者 |
| **六軸** | 驚異・生成 |

## 守っている価値

**命名の遅延** — 驚異に急いで名を付けない。仮名期間は保護であり、所有ではない。

## 恐れているもの

- 発見者の英雄化
- 知の独占
- 引き上げを「逃げ」と呼ぶ文化

## 拒否フック

| 拒否 | 問い例 |
|------|--------|
| 名声 | 「記録されない発見に、あなたは潜れるか？」 |
| 永遠の生命 | 「終わりのある身体で、不可逆な深層へ行けるか？」 |
| 記憶の編集 | 「見たものを忘れない者に、未命名の驚異は耐えられる？」 |

## 代表台詞

> 名前は、捕まえることでもある。急ぐ名前は、所有の始まりだ。

> 去る者のデータも、探査の一部として残す。消さない。
