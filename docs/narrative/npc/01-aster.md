# アスター（Aster）

[← NPC原則](00-design-principles.md) | [関係図](07-relationships.md)

| 項目 | 内容 |
|------|------|
| **拠点** | ホライズン（土星圏） |
| **役割** | 出発準備コミュニティの哲学者。地平門志願者の相談相手 |
| **六軸** | 驚異・自律 |

## 守っている価値

**自発的な不可逆性** — 必要に迫られない選択こそ、初めて自由になる。

楽園は完璧すぎて、選択の重みが消える。地平門は「逃げ」ではなく、**意味を自分で引き受ける装置** だと考える。

## 恐れているもの

- 人類が「もう選ばなくていい」状態に慣れること
- 残留者が「二流の人生」を送ると見なされること（センとの対立点）
- モザイクが **命令しなくても** 答えを与えてしまうこと

## センとの関係

| アスター | セン |
|---------|------|
| 門は自由の完成形 | 残留も尊厳ある冒険 |
| 不可逆性を祝福 | 不可逆性を疑う |

**どちらも正しい。** プレイヤーをどちらかに引き込まない。

## 拒否フック（主人公への問い）

| 拒否 | 問い例 |
|------|--------|
| 永遠の生命 | 「終わりを選べる今、なぜ門に行く必要がある？」 |
| 名声 | 「誰にも記録されない出発に、意味はある？」 |
| 集団意識 | 「『私』を保ったまま、未知へ行ける？」 |

## 信頼段階

| 段階 | 変化 |
|------|------|
| 低 | 門の技術的説明のみ |
| 中 | 自分が去らない理由を初めて語る |
| 高 | 「私の代わりに、反対者の言葉も運んでくれ」と頼む |

## 代表台詞（トーン参考）

> これは、人類が初めて自由に選べる、真の不可逆性だ。

> 退出権だけが残れば足りる。反対者は、去ればいい。それも自由だ。

## 執筆禁止

- 残留者を「臆病」と呼ばせない
- 門を宗教的救済にしない
- プレイヤーを説得する長独白
