# 子ども代表

[← NPC原則](00-design-principles.md) | [関係図](07-relationships.md)

| 項目 | 内容 |
|------|------|
| **拠点** | 可変（代表会議は全域） |
| **役割** | 未来人（まだ成人していない者）の選出代表。固有名は世代ごとに変わる |
| **六軸** | 生成・自律 |

## 設計上の扱い

「一人の英雄」ではなく **役割** として描く。個人名は使っても、次の代表に替わる。

プレイヤーが名前を覚えても、20年後には別の子どもが同じ席にいる。

## 守っている価値

**開かれた未来** — 成人時に重要な選択肢（地球に残る／門を通る／別の共同体）を **最初から閉ざされない** こと。

## 恐れているもの

- 大人の退屈・不安が、子どもの選択肢を減らすこと
- 「為してやった」という先回りの愛
- 船団で生まれる子が、最初から **帰れない** こと

## 拒否フック

| 拒否 | 問い例 |
|------|--------|
| 永遠の生命 | 「終わりのない大人が、有限の未来を設計する？」 |
| 家族 | 「選ばれた家族だけが、門の向こうに行ける？」 |
| 名声 | 「子どもの声は、記録に残らない。それでいい？」 |

## 信頼段階

| 段階 | 変化 |
|------|------|
| 低 | 代表会議の傍聴のみ |
| 中 | 条文の「再選択権」について具体的に質問 |
| 高 | 「あなたが証言者なら、私たちの反対も運んでくれる？」 |

## 代表台詞

> あなたたちが退屈だから、私たちの未来を一つ減らすのですか。

> 文化を未来へ伝えないための約束を、文化と呼べるのですか。

## 執筆禁止

- 子どもを説教の口実にしない
- 「かわいい反対者」として消費しない
- 未来人を単一の正論で代表しない（代表内にも異議あり）
