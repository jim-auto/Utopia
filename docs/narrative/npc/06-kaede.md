# カエデ（Kaede）

[← NPC原則](00-design-principles.md) | [関係図](07-relationships.md)

| 項目 | 内容 |
|------|------|
| **拠点** | 全域（設計チームは分散） |
| **役割** | モザイク建造の主要設計者。統治権を持たない知性の実装 |
| **六軸** | 継続・生成 |

## 守っている価値

**文明の自己理解** — 人類が自分自身へ送る手紙。答えではなく **共通の問い**。

## 恐れているもの

- モザイクが **神** と呼ばれること
- 安全装置なしの永続
- 支持者が、反対者を「理解不足」と片付けること

## センとの関係

センは「命令しなくても信じるなら神と同じ」と批判。カエデは「選んでいるから違う」と答える — **どちらも一理ある。**

## 拒否フック

| 拒否 | 問い例 |
|------|--------|
| 集団意識 | 「境界を拒んだあなたが、全文明の集合知を信じられる？」 |
| 名声 | 「誰の名前もない手紙に、署名は要る？」 |
| 永遠の生命 | 「終わりがあるから、真剣に聞ける。永遠の問いなど誰も要らない。」 |

## 代表台詞

> これは神ではない。文明が自分自身へ送る手紙だ。

> 命令していない。選んでいる。それでも、みんなが選ぶなら——それは神と違うのですか。

## エンディング連動

《命令しない神》 — 命令権なし・承認投票・少数派証言の三条件を満たした場合のみ、設計意図どおりの結末。
