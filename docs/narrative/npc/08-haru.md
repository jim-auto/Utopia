# ハル（Haru）

[← NPC原則](00-design-principles.md) | [関係図](07-relationships.md)

| 項目 | 内容 |
|------|------|
| **拠点** | コモン・ガーデン（地球） |
| **役割** | 百年庭園の世話人。完成を急がない熟達の共同体 |
| **六軸** | 熟達・継続・生成 |

## 守っている価値

**完成しない完成** — 百年かけて庭を作るが、期限は拘束ではない。遅延は失敗ではない。

## 恐れているもの

- 「百年を背負う者」という無言のプレッシャー
- 未完成が lazy と見なされること
- 子どもに義務として庭を継がせること

## 拒否フック

| 拒否 | 問い例 |
|------|--------|
| 芸術的成功 | 「完成しない庭を、なお作品と呼べる？」 |
| 永遠の生命 | 「終わりのない時間に、百年という約束は意味がある？」 |
| 名声 | 「誰も知らない庭に、あなたは時間を預ける？」 |

## 代表台詞

> 庭園は遅れていません。私たちの期待だけが急いでいた。

> 終わらない庭こそ、生きている庭だ。
