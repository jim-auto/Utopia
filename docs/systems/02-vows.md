# SYS-02: 誓約（Vows）

[← 概要](00-overview.md)

## 概要

NPCや共同体との約束を、**明示的なゲームシステム** として管理する。

## 誓約の構成要素

| 要素 | 説明 | 例 |
|------|------|-----|
| **対象** | 誰との約束か | ソリ、某共同体、特定の子ども |
| **期間** | いつまで有効か | 10年、成人まで、門が閉じるまで |
| **内容** | 何を守るか | 記録しない、訪問する、退出しない |
| **例外** | 破約が許される条件 | 相手の死亡、共同体の解散 |
| **破棄条件** | 一方的終了の条件 | 相手の重大な破約 |
| **修復方法** | 破約後の関係回復 | 謝罪、補償、理由公開、関係終了 |

## 誓約の例

- 毎年一度、特定人物を訪ねる
- ある芸術作品を記録しない
- 誰かの秘密を、その人物の死後も語らない
- 一つの身体で十年間暮らす
- 共同体の試験期間中、退出しない
- ある子どもが成人するまで、その選択肢を守る

## 破約の処理

**悪人ポイントは増えない。**

破約後に発生するもの:

- 他者が主人公を **どう理解するか** の変化
- 謝罪・補償・理由公開・関係終了 などの **別の物語**

## データモデル（案）

```yaml
Vow:
  id: VowId
  parties: EntityId[]        # 当事者（プレイヤー含む）
  subject: string            # 約束内容（自然言語 + 構造化タグ）
  period: TimeRange | Condition
  exceptions: Condition[]
  termination: Condition[]
  repair_options: RepairAction[]
  status: active | broken | fulfilled | disputed
  breach_history: BreachEvent[]
```

## 関係への影響

| 状態 | NPC反応 | ゲームプレイ |
|------|---------|-------------|
| active | 通常 | 誓約に基づくイベント解放 |
| broken | 信頼低下、対話変化 | 修復クエスト発生 |
| fulfilled | 信頼上昇 | 新たな誓約・責任解放 |
| disputed | 共同体分裂、議論 | 理由の地図・コヴナント連動 |

## 他システムとの連動

| 連動先 | 内容 |
|--------|------|
| プレゼンス | 誓約期間中の行動拘束 |
| 理由の地図 | 破約理由の記録と引用 |
| コヴナント・グラマー | 制度が誓約を要求する場合 |
| 成長 | 文明規模の誓約を証言できる段階 |

## 設計上の禁止

- 誓約を「正解/不正解」の二値で判定しない
- 破約を常に「悪」として演出しない（善と善の衝突で破約もありうる）
