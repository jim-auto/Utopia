# SYS-04: 理由の地図（Map of Reasons）

[← 概要](00-overview.md)

## 概要

「証拠」ではなく、**他者の理由** を集めるシステム。議論・憲章起草・公共決定の中核。

## コアルール

- 同じ発言でも、**誰が・何を失い・どの状況で** 語ったかによって意味が変わる
- 議会で発言を都合よく切り取れば、**その人物から抗議** される
- 会話は正解選択肢を当てるゲームではなく、**他者の理由を歪めずに組み合わせる** ゲーム

## 勝利条件: 安定した異議

全会一致ではない。反対者が賛成に転じなくても、以下が認められれば **正当な決定** が成立:

| 条件 | 意味 |
|------|------|
| 自分の負担が理解された | 反対者のコストが記録・承認された |
| 退出の権利が残る | コモンズ憲章 #2 の実効 |
| 制度が再検討される | 固定化ではなく、将来の変更余地 |
| 自分の意見が記録された | 少数派の証言が消去されない |

## データモデル（案）

```yaml
Reason:
  id: ReasonId
  speaker: EntityId
  utterance: string
  context:
    situation: SituationId
    loss: string              # 話者が失う/失ったもの
    stake: string             # 何がかかっているか
  timestamp: GameTime
  citations: Citation[]       # 他の理由への参照

Citation:
  reason_id: ReasonId
  excerpt: TextRange
  attribution: EntityId       # 引用元の明示（必須）
  distortion_flag: bool       # 歪めた引用 → 抗議トリガー

Deliberation:
  topic: string
  reasons: ReasonId[]
  objections: Objection[]
  outcome: Decision | Deferred
  dissent_preserved: bool     # 異議記録の有無
```

## 抗議メカニクス

| トリガー | 結果 |
|---------|------|
| 文脈なしの切り取り | 話者が抗議、信頼低下 |
| 反対理由の省略 | 決定の正当性に疑義 |
| 少数派証言の削除 | モザイク/憲章ルートへの影響 |

## 適用場面

- 公共議会（最終章）
- 出発憲章の起草
- コヴナント同意プロセス
- モザイク存続承認

## UI/UX 要件

- 理由カードに **話者・状況・利害** を常時表示
- 引用時は **自動帰属**（手動省略不可）
- 決定画面に **異議欄** を必須表示

## 他システムとの連動

| 連動先 | 内容 |
|--------|------|
| コヴナント・グラマー | 同意・異議の構造化 |
| 誓約 | 約束に関する理由の記録 |
| 成長 | 証言者としての信頼段階 |
