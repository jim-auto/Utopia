# SYS-07: 身体的ゲームプレイ（Embodied Gameplay）

[← 概要](00-overview.md)

## 概要

哲学を会話画面だけに閉じ込めない。地域ごとに異なる **「生の実践」** をアクションとして体験させる。

## 地域別実践

| 地域 | 実践 | 体験する価値 |
|------|------|-------------|
| コモン・ガーデン / 軌道 | 太陽帆を操る軌道航行 | 驚異、熟達 |
| アビス | エウロパ海底での共同探査 | 驚異、関係 |
| アトリエ | 巨大建築の組み立て | 熟達、生成 |
| アトリエ | 音楽の演奏と即興 | 一回性、関係 |
| パリンプセスト | 記憶空間の再構築 | 継続、自律 |
| コーラス | 複数身体を切り替える集団意識 | 関係、自律 |
| 各所 | 救助、スポーツ、環境適応 | 関係、熟達 |
| ジェネシス・フォージ | 新しい生物の行動・感覚設計 | 生成、驚異 |

## 戦闘の位置づけ

**通常の戦闘は中心に置かない。**

| 存在するもの | 目的 |
|-------------|------|
| 競争 | 技能、遊び |
| 模擬戦 | 信頼、自己制約の成立 |

→ 相手を殺して戦利品を得るため **ではない**。

## 実装方針

| 方針 | 理由 |
|------|------|
| 各実践は独立ミニゲームまたはモード | 100時間の多様性 |
| 習熟は成長（信頼）に接続、攻撃力に接続しない | 成長設計と整合 |
| 失敗は死亡ではなく関係・機会の変化 | 楽園設定と整合 |

## 他システムとの連動

| 連動先 | 内容 |
|--------|------|
| プレゼンス | 長期修行 = 他イベント見逃し |
| 誓約 | 「十年一身体」等の身体制約 |
| 意味生態系 | 実践が共同体の「形」を体現 |
| 成長 | 習熟 → 責任の拡大 |

## コンテンツ配分

実践習熟・探索・小規模物語: **10〜20時間**（GDD §10）
