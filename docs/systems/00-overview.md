# システム仕様 — 概要

[← GDD 目次](../gdd/00-index.md) | [用語集](../glossary.md)

## 設計原則

1. **単一スコアを作らない** — 幸福度・自由度のような合算メーターは存在しない
2. **プレイヤーは命令できない** — 参加・提案・証言・約束のみ
3. **時間は巻き戻らない** — セーブ破壊演出は使わず、経過と見逃しで重みを作る
4. **善と善の衝突** — 道徳は最適化問題ではなく、トレードオフの設計

## システム間の依存関係

```
プレゼンス ──→ 誓約（時間的競合）
    │
    ├──→ コヴナント・グラマー（制度試行期間）
    │         │
    │         └──→ 意味生態系（共同体の形）
    │
    ├──→ 理由の地図（議会・憲章起草）
    │
    └──→ 成長（信頼の段階的拡大）

身体的ゲームプレイ ──→ 全システム（思想の非会話体験）
```

## プレイヤー権限マトリクス

| 行為 | 可否 | 備考 |
|------|------|------|
| 命令・強制 | ✗ | |
| 共同体への滞在・参加 | ✓ | プレゼンス制約あり |
| 制度試験の提案 | ✓ | コヴナント・グラマー経由 |
| 出発憲章の起草・証言 | ✓ | 理由の地図と連動 |
| 誓約の締結・破棄 | ✓ | 関係・評価に影響 |
| 社会全体の完全解決 | ✗ | 創作規則 #9 |
