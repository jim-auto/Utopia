# SYS-01: プレゼンス（Presence）

[← 概要](00-overview.md)

## 概要

本作で最も重要な資源は、金でも鉱石でもなく、**主人公がどこに居合わせるか** である。

## コアルール

- 一つの期間に参加できる **重要な出来事は限られる**
- 友人の演奏会に行けば、別の共同体の設立には立ち会えない
- 火星で十年間修行すれば、地球の子どもは成長している
- **世界は主人公を待たない**

## プレイヤー体験の目標

「すべてのクエストを回収する英雄」ではなく、**何かを選ぶことで他を見送る人間** にする。

## データモデル（案）

```yaml
PresenceSlot:
  period: TimeRange          # ゲーム内期間（例: 第3期 5年目）
  events: Event[]            # 同時競合する重要イベント
  capacity: 1                # 同時参加可能数（通常1）
  player_choice: EventId?    # プレイヤーが選んだイベント
  missed_events: EventId[]   # 見逃したイベント（失敗ではない）
```

## イベント競合の例

| 期間 | イベントA | イベントB | 見逃しの結果 |
|------|----------|----------|-------------|
| 第2期 | ソリの初演準備 | アビス深層探査 | 探査報告はNPC口頭のみ、関係は維持 |
| 第3期 | 制度試行の立会 | 子どもの成人式 | 成人式は後から聞く、関係に距離 |

## UI/UX 要件

- 競合イベントを **事前に可視化** する（サプライズではなく選択の重み）
- 見逃した出来事は **ログ・手紙・再訪時の変化** で間接的に伝える
- 「取り消し」UIは提供しない（時間巻き戻しなし）

## 他システムとの連動

| 連動先 | 内容 |
|--------|------|
| 誓約 | 約束期間中のプレゼンス拘束 |
| コヴナント・グラマー | 試行期間中の滞在義務（任意の誓約） |
| 成長 | 長期滞在で共同体への信頼が深まる |

## 非機能要件

- 100時間プレイでイベント競合が **数百回** 発生しうる → タイムラインUIの性能に注意
- ニューゲーム+では別の競合パターン
