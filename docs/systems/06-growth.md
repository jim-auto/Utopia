# SYS-06: 成長（Growth）

[← 概要](00-overview.md)

## 概要

レベルアップで攻撃力は上がらない。長く実践を続けることで **「任せてもらえる責任」** を増やす。

## 成長の定義

> 強くなることではなく、**自分の言葉が、他者の未来にとって重みを持つ人になること**

## 段階モデル

| 段階 | 社会的位置 | 解放される行為 |
|------|-----------|---------------|
| 1. 客人 | 共同体の外来者 | 滞在、観察、小さな誓約 |
| 2. 参加者 | 実践に加わる | 設計への意見、中程度の誓約 |
| 3. 預かり者 | 秘密・将来を託される | 制度試行への共同提案 |
| 4. 証言者 | 文明規模の約束を証言 | 出発憲章起草、公共議会の中心 |

## 成長要因（非数値）

| 要因 | 説明 |
|------|------|
| 実践の継続 | 地域別アクションの習熟 |
| 誓約の履行 | 破約なく期間を守った実績 |
| 関係の深度 | 特定NPCとの時間と信頼 |
| 制度試行への関与 | コヴナントの設計・再訪 |
| 理由の正確な伝達 | 理由の地図での公正な引用 |

## データモデル（案）

```yaml
TrustTier:
  community: CommunityId → TierLevel
  npc: NPCId → TrustLevel
  civic: WitnessTier       # 公職としての証言段階

# 数値HP/攻撃力は存在しない
Responsibility:
  unlocked_actions: ActionId[]
  narrative_weight: enum     # 低 | 中 | 高（UI表示用、最適化不可）
```

## 他システムとの連動

| 連動先 | 内容 |
|--------|------|
| プレゼンス | 長期滞在が関係深化に必要 |
| 誓約 | 高次の誓約は段階解放 |
| 理由の地図 | 証言者段階で憲章起草権 |
| 身体的ゲームプレイ | 実践習熟が信頼の基盤 |

## 設計上の禁止

- 戦闘力・レベル数値の表示
- 成長が「正解ルート」への自動解錠にならないこと
