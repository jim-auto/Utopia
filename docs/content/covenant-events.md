# 18本の長編コヴナント事件 — 企画一覧

[← GDD 目次](../gdd/00-index.md)

想定プレイ時間: **25〜30時間**（全事件）。各事件は **設立前 → 試行初期 → 摩擦中期 → 次世代後期** の四期再訪を持つ。

## 設計原則

| 原則 | 内容 |
|------|------|
| 正解なし | 各事件は2つ以上の「本物の価値」を衝突させる |
| 合算なし | 六軸スコアで最適解を示さない |
| 解釈 | NPCはルールを実行・抜け道・儀式化・拒否する |
| プレイヤー | 命令ではなく提案・滞在・証言のみ |

## 六軸タグ

`自` 自律 / `熟` 熟達 / `関` 関係 / `継` 継続 / `生` 生成 / `驚` 驚異

## プロトタイプで体験できるループ

### 事件 #05 — 百年庭園（コモン・ガーデン）

```
第二章末 → 条項設計 → 10年後再訪 → 第三章へ
```

### 事件 #04 — 忘れられる権利（パリンプセスト）

```
第三章で選択 → 条項設計 → 3年後再訪 → 出発憲章試行へ
```

### 事件 #12 — モザイクの承認投票（第四章）

```
第四章 → 存続条件を設計 → 1年後評価 → 出発憲章議会 → エンディング
```

安全装置3種（命令権なし・承認投票・少数派証言）を選ぶと **《命令しない神》** エンディングが解放される。

### 事件 #03 — 出発憲章の試行（ホライズン）

```
制度を組む → 5年試行 → 再訪（解釈・摩擦・儀式化）→ 議会（理由の地図）→ 出発憲章
```

ブラウザ版では **#03 出発憲章の試行** を中心に、条項選択が5年後の社会像と議会に影響します。
