## 作品・公職

## 世界・制度

| 用語 | 読み | 説明 |
|------|------|------|
| **コモンズ憲章** | こもんずけんぽう | 文明の根幹。生存保障、退出権、身体・記憶・寿命の自己選択、他者の手段化禁止、未来の開放 |
| **コモンズ** | こもんず | 透明な自動化基盤。物流・医療・翻訳・設計・環境管理を担うが、善い人生を決定しない |
| **地平門** | ちへいもん | 太陽系外縁の自然発生ワームホール。約90年後に閉じ、一方通行 |
| **開かれた未来** | ひらかれたみらい | 子どもが成人時に重要な選択肢を持てるよう守る倫理。船団設計の争点 |
| **モザイク** | もざいく | 統治権を持たない知性。全人類の経験を読み「次に目指すべき目的」を提案するのみ |

## ゲームシステム

| 用語 | 英語名 | 説明 |
|------|--------|------|
| **プレゼンス** | Presence | 時間と注意の資源。同時に参加できる重要イベントは限られる |
| **誓約** | Vows | 対象・期間・例外・破棄条件・修復方法を持つ明示的約束システム |
| **コヴナント・グラマー** | Covenant Grammar | 社会制度を文章論理で組み、実地試行するシステム |
| **理由の地図** | Map of Reasons | 他者の理由を文脈付きで集め、歪めずに組み合わせる議論システム |
| **意味生態系** | Meaning Ecosystem | 六つの価値の形（合算なし）で共同体を記述する枠組み |
| **安定した異議** | Stable Dissent | 全会一致ではない正当な決定。負担の理解・退出権・再検討・記録が条件 |

## 意味生態系 — 六つの形

| 用語 | 説明 |
|------|------|
| **自律** | 自分の生を自分で選べる |
| **熟達** | 時間をかけて何かを身につける |
| **関係** | 特定の他者と結びつく |
| **継続** | 過去と未来の物語を持つ |
| **生成** | 自分より後に残る何かへ関与する |
| **驚異** | 完全には制御できないものに出会う |

## 製造できない価値

| 用語 | 説明 |
|------|------|
| **注意** | 同時にすべての人の隣にいられない |
| **特定の人との時間** | コピー経験は共有した過去そのものではない |
| **信頼** | 継続した行為によってのみ成立 |
| **約束** | 他の可能性を捨てたとき初めて重みを持つ |
| **一回性** | 完璧な再現と「そのときそこにいたこと」は異なる |
| **未来人の同意** | 未出生者から許可を得られない |
| **共通の歴史** | 幸福な個人の集合は自動的に共同体にならない |

## エンディング

| 名称 | 概要 |
|------|------|
| **開かれた地平** | 最小限の技術と権利のみ。各世代が自分で決める |
| **庭園の群島** | 価値の異なる複数小船団 |

| **ここで十分である** | 門を使わない |
| **有限なる旅** | 出発者のみ回復・バックアップ限定。子どもには選択肢を残す |
