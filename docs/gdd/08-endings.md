# 8. エンディング

[← 目次](00-index.md)

エンディングは「善・悪」ではなく、**得たものと失ったもの** を描く。

同じ結論を選んでも、過程が違えばエピローグは変わる。思想ではなく、**その思想を他者にどう扱ったか** が結末の質を決める。

---

## 1. 《開かれた地平》

| | |
|---|---|
| **内容** | 完全な技術と最低限の権利だけを携えて出発。共通目的や固定文化を設定せず、各世代が自分で決める |
| **得る** | 最大限の未来可能性 |
| **失う** | 強い共通物語と方向性 |

## 2. 《庭園の群島》

| | |
|---|---|
| **内容** | 一つの船団ではなく、異なる価値を持つ複数の小船団が通過。互いに連絡はできるが統一されない |
| **得る** | 価値の複数性 |
| **失う** | 人類全体としての一体感 |

## 3. 《選ばれた大仕事》

| | |
|---|---|
| **内容** | 永久の目的ではなく、百年間だけ共有する文明的プロジェクトを選ぶ（異星生命の保護、銀河規模の芸術、知性の記録など）。必ず失効条項付き |
| **得る** | 連帯、世代を超えた達成 |
| **失う** | 目的に参加しない人生が周縁化される危険 |

## 4. 《命令しない神》

| | |
|---|---|
| **内容** | モザイクを完成させる。命令権なし、一定期間ごとに存続承認、少数派の証言を消去不可 |
| **得る** | 共通の問いと文明的自己理解 |
| **失う** | 「モザイクがそう言った」という自発的服従の誘惑 |

## 5. 《ここで十分である》

| | |
|---|---|
| **内容** | 門を使わない。「成長し続けなければならない」という強迫そのものを拒絶。門が閉じた後、太陽系内部の関係と文化を深める |
| **得る** | 現在の生への肯定 |
| **失う** | 二度と戻らない可能性 |

## 6. 《有限なる旅》

| | |
|---|---|
| **内容** | 出発者は自らに限り回復・バックアップを限定した人生を選ぶ。子どもには成人時に安全技術を回復できる選択肢を残す |
| **得る** | 自由に引き受けた一回性 |
| **失う** | 実際の別れ、回復不能な喪失 |

---

## エピローグの変化要因

- 人々を急かしたか
- 異議を残したか
- 約束を守ったか
