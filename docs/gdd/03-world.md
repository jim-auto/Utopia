# 3. 世界観

[← 目次](00-index.md)

## 時代

**25世紀末**

- 人類は太陽系全域に居住
- 約200年間、戦争・飢餓・極端な貧困・強制労働のない社会を維持
- 一つの政府や統治AIではなく、**透明な自動化基盤** と **多数の自治共同体** から構成
- AIは物流・医療・翻訳・設計・環境管理を担うが、**何が善い人生かを決定する権限は持たない**

## 社会の状態

- 幸福は偽装されていない
- 裏で搾取される階級もない
- AIが感情を操作している事実もない
- **社会は本当に機能している**

## コモンズ憲章（文明の根幹）

1. 生存と回復は無条件に保障される
2. いかなる共同体からも退出できる
3. 身体・記憶・寿命を本人が選択できる
4. 他者を自分の目的の手段として所有できない
5. 子どもや新たに創造される人格の未来を過度に閉ざしてはならない

## 楽園の姿 — 六つの主要地域

単一文化ではなく、無数の「生の様式」が並存する文明の群島。

| 天体 | 名称 | 概要 |
|------|------|------|
| 地球 | **コモン・ガーデン** | 再野生化された大陸と祝祭・学習・交流の都市。生活の基盤。ほとんどの人が安心して暮らす |
| 月 | **パリンプセスト** | 人類の記録・個人の記憶・失われた文化を保存する記憶都市。「忘れる権利」と「歴史を残す義務」が衝突 |
| 火星 | **アトリエ** | 都市全体を数十年かけて一つの芸術作品にする人々、極端な技能を磨く人々、任意の競技に人生を捧げる人々 |
| 金星 | **コーラス** | 複数の人格が一時的に感覚や記憶を共有する共同体。孤独を克服できるが「私」の境界が変わる |
| エウロパ | **アビス** | 未知の海と生命を探索する研究共同体。安全に帰還できる技術はあるが、未知と向き合うこと自体を目的とする |
| 水星 | **ジェネシス・フォージ** | 新しい身体・感覚器官・生物種・人格形態を生み出す場所。新生命は「未来への贈り物か、勝手な設計か」を問う |
| 土星圏 | **ホライズン** | 物語の中心となる **一方通行の星間門** と、出発船団の建造地 |
