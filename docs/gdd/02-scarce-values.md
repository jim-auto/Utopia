# 2. この世界で、なお希少なもの

[← 目次](00-index.md)

## 前提

物質、エネルギー、住居、医療、娯楽、知識は **不足していない**。

## 製造できない価値

| 価値 | なぜ代替できないのか |
|------|---------------------|
| **あなたの注意** | 同じ瞬間に、すべての人の隣にはいられない |
| **特定の人との時間** | コピーされた経験は、共有した過去そのものではない |
| **信頼** | 装置で生成できず、継続した行為によってのみ成立する |
| **約束** | 守るために他の可能性を捨てたとき、初めて重みを持つ |
| **一回性** | 完璧な再現と「そのときそこにいたこと」は同じではない |
| **未来人の同意** | まだ生まれていない者から許可を得ることはできない |
| **共通の歴史** | 無数の幸福な個人がいても、自動的に共同体にはならない |

## 設計への含意

価値の中心が **「所有」から非代替性** へ移る。

無限に物を作れる時代でも、価値を持つのは「何を作ったか」ではなく、**誰と、どれだけの未来をそこに預けたか** である。
