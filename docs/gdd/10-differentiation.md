# 10. 既存作品との差別化

[← 目次](00-index.md)

| 作品 | 既存作の中心的な遊び | UTOPIA の差別化 |
|------|---------------------|----------------|
| **Civilization** | 都市・文明を発展させ、時代を進み、外交・統治・成長を管理。最大の帝国を築く | 文明を大きくしない。領土・人口・技術を最大化せず、完成した文明で「どの制約を正当に選べるか」を設計。勝利条件ではなく **継承条件** を作る |
| **Stellaris** | 星系を探索し、帝国を築き、種族・外交・戦争を通じて銀河へ拡大 | 銀河を所有するゲームではない。出発する必要のない文明が、なぜ未知へ向かうのかを問う。マップの対象は領土ではなく **価値観と約束** |
| **Outer Wilds** | タイムループする星系を探索し、知識によって固定された謎を解く | 時間は巻き戻らない。知識を集めるほど答えが明確になるのではなく、**選択の責任** が増える。「何が起きたか」ではなく「何を選ぶべきか」 |
| **Disco Elysium** | 探偵という一人の人物を、独自の技能・会話システムによって形成するRPG | 思想を主人公の内面だけに置かず、制度・都市・子ども・数十年後の社会へ **外在化**。人格形成から文明の自己形成へスケールを広げる |
| **FF12** | ガンビットによって仲間の行動条件を細かく設定し、戦闘を自動化・最適化 | コヴナント・グラマーは社会の条件を組むが、最適化対象となる総合スコアが存在しない。人間はルールを解釈し、成長し、異議を唱えるため **完全自動化できない** |
| **MGS2** | デジタル時代に、記憶・生き方・文化を未来世代へ何として伝えるかを主題 | 同じ継承の問いを、陰謀の暴露ではなく、プレイヤーが設計する **憲章と世代シミュレーション** に変える。隠された支配者はいない |
| **MGS4** | 戦争が経済システムとなり、兵士の「生の充足」まで戦争へ回収される世界 | 戦争経済も情報統制も既に克服されている。その上で、人間が自由意思から **共通目的や神的権威を再建** する可能性を扱う |
