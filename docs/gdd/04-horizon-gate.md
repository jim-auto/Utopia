# 4. 物語の発端 — 地平門

[← 目次](00-index.md)

## 発見

太陽系外縁で、自然発生した **一時的なワームホール** が発見される。

| 項目 | 内容 |
|------|------|
| 向こう側 | 人間が居住可能な星系 |
| 危険性 | 罠ではない。観測結果も正しい |
| 門の寿命 | 約90年後に閉じる |
| 通過の性質 | **二度と太陽系へ戻れない**（一方通行） |

## 核心的な問い

人類は **逃げる必要がない**。地球は美しく、安全で、幸福である。

> **何の必要もないのに、我々は楽園を去るべきか**

## 同意の非対称

| 主体 | 選択 |
|------|------|
| 成人 | 自発的に去ることは認められる |
| 向こう側で生まれる子ども | 地球へ戻る選択肢を **最初から持たない** |

## 船団が持っていくもの

- 完全な安全技術か
- 死を克服する医療か
- 人類の文化全集か
- 新しい世界が自ら価値を作れるよう、**何も残さない** べきか

## 問題の性質

「誰が支配するか」ではない。

> **現在の人類が、未来の人類にどこまで先回りしてよいか**
