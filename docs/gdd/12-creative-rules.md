# 12. 絶対に破ってはいけない創作上の規則

[← 目次](00-index.md)

1. **コモンズのインフラは最後まで信頼できる**
2. **幸福は薬物や洗脳による偽物ではない**
3. **裏で世界を支配するAIや秘密結社を出さない**
4. **最終盤に侵略者や終末災害を出して、通常の英雄物語へ逃げない**
5. **いずれかの思想集団を秘密のカルトやテロ組織にしない**
6. **楽園に残ることを臆病、出発することを高尚と決めつけない**
7. **人間は暴力がなければ退屈する、という単純な人間観にしない**
8. **唯一の正解エンディングを作らない**
9. **プレイヤーが社会全体を完全に解決できないようにする**
10. **それでも、この世界をプレイヤーが心から守りたいと思えるようにする**
