# 7. 代表的なクエスト

[← 目次](00-index.md)

## 「最後の初演」

### 設定

火星の音楽家 **ソリ** が、一度だけ演奏され、録音も再演もされない交響曲を作ろうとする。

瞬時に音楽を生成できる時代に、作品を価値あるものにするのは希少なデータではなく、**数千人が「一度だけ」という約束を守ること** だと考えている。

### プレイヤーの関与

- 会場を建設する
- 演奏者と練習する
- 約束の範囲を決める

### 20年後

当時の演奏者が曲の断片を自分の子どもへ教える。

| 立場 | 主張 |
|------|------|
| 共同体 | 「誓約違反だ」 |
| 演奏者 | 「自分の記憶まで共同体の所有物ではない」 |
| 子ども | 「文化を未来へ伝えないための約束を、文化と呼べるのですか」 |

### 解決の方向（正解なし）

| 選択 | 守る価値 | 傷つける価値 |
|------|---------|-------------|
| 誓約を厳格に維持する | 一回性 | 文化継承 |
| 個人の記憶からの継承を認める | 自由 | 共同体の約束 |
| 原曲ではなく変奏として伝える | 折衷 | 双方の純粋性 |
| 一回性という思想を撤回する | 文化継承 | 一回性 |

それぞれ、**一回性・自由・文化継承** という本物の価値を守り、別の価値を傷つける。
