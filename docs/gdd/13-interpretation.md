# 13. 「楽園のその後」の最も面白い解釈

[← 目次](00-index.md)

最も面白い解釈は、虚無でも退廃でもない。

## 楽園の定義

楽園とは、**問題がなくなった世界** ではない。

> **問題を、他者に押し付けずに選べるようになった世界**

## 欠乏の時代との対比

| 欠乏の時代 | 楽園 |
|-----------|------|
| 食べるために働く | その言い訳がない |
| 生き残るために争う | |
| 病気を治す | |
| 敵を倒す | |

## 楽園で人間が直面すること

- 何を愛するか
- 誰と時間を使うか
- 何を完成させずに残すか
- **どの約束によって、自分の未来を狭めるか**

それらを **自分たちで引き受けなければならない**。

## 「神の再発明」の意味

暴君を欲しがることではない。

> **選択し続ける責任から解放してくれる、最後の答えを欲しがること**
