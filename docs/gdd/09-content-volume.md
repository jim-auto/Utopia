# 9. 100時間遊べる構造

[← 目次](00-index.md)

マップアイコンの反復ではなく、**時間による再訪** でボリュームを作る。

## 時間配分（想定）

| 内容 | 想定時間 |
|------|---------|
| 序章・地球圏 | 4〜6時間 |
| 六つの主要地域 | 45〜55時間 |
| 18本の長編コヴナント事件 | 25〜30時間 |
| 主要人物の関係・誓約 | 12〜15時間 |
| 最終議会・出発 | 7〜10時間 |
| 実践習熟・探索・小規模物語 | 10〜20時間 |

| プレイスタイル | 時間 |
|---------------|------|
| メインストーリーのみ | 35〜45時間 |
| 主要な結果を見届けるプレイ | 90〜110時間 |

## 再訪モデル

一つの地域を一度攻略して終わりにはしない。

**例:** 最初は子どもだった人物が、20年後には制度の批判者になり、50年後には主人公が作った制度を守る側になる。

### 同一地点の四期

| 期 | 状態 |
|----|------|
| 設立前 | 制度が存在しない |
| 理想に満ちた初期 | 設計意図が可視 |
| 問題が表面化した中期 | 解釈・抜け道・摩擦 |
| 次世代が再解釈した後期 | 継承と変容 |

## リプレイ価値

- 一週の中でも選択が必要（すべての出来事に参加できない）
- ニューゲームでは別の約束と別の人物を選び、**別の文明史** が成立する
