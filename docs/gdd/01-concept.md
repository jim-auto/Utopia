# 1. ゲームコンセプト

[← 目次](00-index.md)

## ジャンル

三人称探索アドベンチャー ＋ ナラティブRPG ＋ 社会制度シミュレーション

## プレイヤーが「しない」こと

- 文明を征服しない
- 資源を奪わない
- 悪のAIを破壊しない

## プレイヤーが「する」こと

- 各地の共同体で異なる生き方を実際に体験する
- 他者と約束を結ぶ
- 社会制度を試作する
- その結果を数十年後に見届ける

## 中心命題

> 意味には「取り消せなさ」が必要である。  
> しかし正義には「退出できること」が必要である。

人間は、何でもやり直せる世界では選択の重みを失いやすい。一方、やり直せない制度は人を拘束する。

本作はこの矛盾を、**会話・約束・時間経過・制度設計・探索** によって遊ばせる。

## 基本動詞の置き換え

| 従来 | 本作 |
|------|------|
| 集める | 出会う |
| 支配する | 約束する |
| 勝つ | 生きる → 見届ける → 改める |

## プレイヤーファンタジー

世界を救うことではない。

**他者の自由を壊さずに、何かを本当に大切にすること。**

それこそが「楽園の後」に残る、最大の冒険である。

## 最終的な問い

「人類は目的を見つけられるか」ではない。

> **人類は、唯一の目的を強制せず、それでも人生を無意味にしない社会を維持できるか**
